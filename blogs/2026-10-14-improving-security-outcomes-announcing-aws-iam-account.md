Sonrai Security Partners with AWS to launch Bring-Your-Own Role capabilities to AWS Accounts. We’re proud to announce that Sonrai Security is an AWS Launch Partner for AWS IAM account access manager (AAM), the newest addition to AWS’s identity and access management feature list. This joint collaboration extends critical security capabilities across our customers’ AWS organizations.
